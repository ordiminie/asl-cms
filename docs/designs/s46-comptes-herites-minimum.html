AELes Amis de l'Étang
Proposition retenue pour le design system (§2.1)
1. Deux éléments seulement : <AssociationMark size="public" /> à gauche, lien vers « / » ; bouton outline « Se déconnecter » à droite.
2. Bouton : icône LogOut 20 px + libellé, 48 px (56 px sur mobile). Jamais l'icône seule.
3. Pas de menu, d'avatar, de cloche, de sélecteur, de tiroir. La navigation /dashboard ↔ /account passe par des liens dans le contenu.
4. Fond background, filet 1 px border, sans ombre ; padding vertical 16 px (12 px sur mobile) ; intérieur aligné sur la colonne max-w-[1000px], marges 16 px sous 1 024 px.
5. Mobile : le nom passe à la ligne (2 lignes max, puis points de suspension) ; le bouton garde toujours son libellé (flex-shrink: 0).
6. « Aller au contenu » : premier élément focalisable, visible au focus, cible <main id="contenu">.
Pas de nom de l'utilisateur dans l'en-tête : le futur « Bonjour {prénom nom} » de s12d le portera dans le contenu.
